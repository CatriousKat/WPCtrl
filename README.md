# WPCtrl
A tool for controlling Windows Phone OS 7.0 and newer. <br>
<br>

<strong>Command support</strong>
| Command | Windows Phone 7.x | Windows Phone 8.x | Windows 10 Mobile |
| :--- | :---: | :---: | :---: |
| `getinfo` | ✅ | ✅ | ✅ |
| `ping` | ❌ | ✅ (only 8.1) | ✅ |
| `battery` | ❌ | ✅ (only 8.1) | ✅ |
| `reboot` | ❌ | ✅ (only 8.1) | ✅ |
| `ls` | ❌ | ✅ | ✅ |
| `copy` | ❌ | ✅ (only 8.1) | ✅ |
| `install` | ❌ | ❌ | ✅ |
| `list-apps` | ❌ | ❌ | ✅ |
| `uninstall` | ❌ | ❌ | ✅ |
| `launch` | ❌ | ❌ | ✅ |
| `terminate` | ❌ | ❌ | ✅ |
| `list-processes` | ❌ | ❌ | ✅ |
| `kill` | ❌ | ❌ | ✅ |
| `screenshot` | ❌ | ❌ | ✅ |
